# Finanças

Painel de finanças pessoais. Abra pela barra lateral do Home Assistant.

## Como começar

1. Em Recorrentes, cadastre as contas fixas (aluguel, assinaturas) e as variáveis (luz, água), marcando "Valor variável" quando o valor muda todo mês.
2. Em Parcelados, cadastre as compras parceladas. Parcelas de cartão ficam só nessa aba; as demais entram no mês de cada parcela.
3. No Início, lance receitas e despesas avulsas e marque como pago ou recebido quando acontecer.

## Ajustes

Se o valor de uma conta variável mudar em um mês, edite o lançamento desse mês no Início. O ajuste fica só naquele mês e não é sobrescrito quando você editar a recorrência.

## Backup

Em Configurações, use Baixar backup antes de atualizar o app ou apagar dados. Importar um backup substitui todos os dados atuais.
